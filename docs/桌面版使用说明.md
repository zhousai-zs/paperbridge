# PaperBridge 桌面版

1. 将完整 ZIP 解压到本机文件夹，双击 **PaperBridge.exe**。请保留同目录的 `_internal/` 和 `models/`，不要单独移动 EXE。
2. 点击“选择 PDF”，可一次添加多份；选择输出文件夹。输出位置会在下次启动时自动填充。
3. 点击“开始转换”。文件按顺序处理，某一份失败不会阻止后续文件。
4. 结束后点击“打开输出文件夹”。每篇论文独立保存，主阅读文件为 `document.md`。

默认标准模式、全部页面、自动 OCR。需要时展开“更多选项”：快速模式、页码（`1-3,5`）、OCR、每段页数和超时。快速模式的公式需特别核对。

进度按已完成的分段更新，识别一个分段期间可能较长时间没有新增页数，活动提示表示仍在处理；不提供估算剩余时间。组装和生成原页图也需要时间。

点击“停止”或处理中关闭窗口，会停止本批转换，保留完整检查点。下次选择相同文件、输出目录和参数，可复用已完成分段；未完成分段重新处理。异常断电可能留下 `.lock`，先确认没有其他转换进程再检查，不要删除其他正在运行的任务锁。

“需复核”表示报告列出了问题；“完成”表示机械检查通过，不代表识别准确率为 100%。关键公式、数字和表格请核对 `source.pdf`、`pages/`、`evidence/`。

**分享、归档或交给 Agent 时保留整个结果文件夹**，避免丢失相对路径引用的图片。告诉 Agent：先读 `AGENT_README.md`，再读 `document.md`。

旧 Web 工作台的结果、`review/` 修订和历史均可保留。本版不提供内置阅读或修订界面，旧修订可通过命令行导出阅读包：

```powershell
.\PaperBridge-CLI.exe export "D:\结果\论文目录" -o "D:\阅读包\论文.zip"
```

命令行也支持 `convert`、`doctor --models`；`gui` / `ui` 打开桌面端。便携包包含标准／快速模式模型，完全在本机处理，无需 Python、API Key 或联网下载。高级模式命令行接口保留，但本包不承诺其模型与质量验证。

设置、临时文件和日志位于 `%LOCALAPPDATA%\PaperBridge`。失败后可展开“错误详情”或打开其中的日志路径；引擎日志位于结果的 `chunks/*/engine.log`。重新解压或更新程序不会删除输出目录中的结果。

适用于 Windows x64；模型和运行环境体积为数 GB，运行时仍需要额外内存、临时空间及输出空间。
